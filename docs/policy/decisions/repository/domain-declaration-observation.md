## Decision

Keep full canonical D1 body and staging bytes as original data. Bind their source,
rules, protocol and manifest to the independently selected original package.
Protocol 4 retains its original unsorted unique contract-list grammar; protocol 5
uses its explicitly adopted sorted grammar. This parser does not adopt protocol 5
execution or perform release construction.

The separate Unix-like domain observer uses one independently provisioned public
source and fixed digest-only review role. Its fixed eight-key source policy has no
default source, numeric workflow, Environment, actor or reviewer provisioning.
Pure workflow rendering verifies original enabled source bytes; no workflow is
published or enabled by this source outcome. Programmer-selected source anchors
and bounded hash-verified original Git membership/ancestry remain separate from
packet data and from actual operator source-approval custody.

Anonymous bounded fixed-host GETs bind latest and exact attempt 1, sole completed
job, fixed workflow and Environment, one approved authorized reviewer and the
distinct title/comment prefixes. Reobserve latest run, approvals and Environment
within one shared deadline. Unknown, incomplete, changing or foreign observations
refuse. Matching run-scoped API data does not certify initial hold, a numeric
deployment-to-job join or actual native execution.

Returned immutable data grants no private introduction, completed staging,
current-generation effect, runtime admission or operating approval capability.
No consumer imports this library yet. Future importing consumers must explicitly
adopt its complete executable/policy closure and retain old package semantics.
Actual source acceptance, independent provisioning, private packet custody,
producer/staging/runtime checks and operating effects remain separate gates.
