# Typed production receipts retain independent review custody
date: 2026-10-04
scope: repository
status: accepted
reopen-when: Review owners, packet schemas, endpoint origins, semantic custody fields or source execution authority change.

## Decision

Typed production qualification is a trusted transport extension, not a new
semantic controller. Separate independently observed Actions execution metadata
from source-bound authorized review assertions about native execution, public
contracts and delivered template/provider compatibility. Exact Actions job names
or original workflow/tool blobs do not by themselves prove runtime versions or
representative native platforms. Unsupported exact execution descriptors refuse;
genuine reviewed raw records remain a separate evidence producer.

Canonical bounded private packets bind original comparison/rules/package/baseline,
selected requirement/tool/profile identities and raw receipt bytes. Their paths
are content-addressed review/packets/<SHA256>.json original regular Git blobs.
Independent trusted producer/authority inputs are not chosen by packet authors.
A mutable active index is a lookup hint only. It never replaces old evidence,
which recovers its original review run and exact approved comment hash.

One fixed public review-only source role uses maintainer numeric actor 101378576,
.github/workflows/release-production-review.yml, review-production-receipt job and
release-production-review Environment. Actual numeric IDs and accepted source are
independently reviewed deployment inputs. The initial source job is statically
disabled; enabling it needs separate reviewed source acceptance and actual operator
setup. The job has no credential, private connection, packet contents, checkout,
artifact or operating effect; platform deployment metadata is explicit.

Fixed-host anonymous GET observes original source/run/attempt=1/sole job and
workflow, Environment numeric identity and complete actual review history.
Exactly one approved authorized comment review:<packet SHA256> binds the human
acknowledgement. Title is an additional check, not independent input authority.
The API supplies no approval timestamp or attempt/job field; current Environment
metadata proves no historical hold policy. Actual first hold and reviewer policy
are separate operator proof. This receipt certifies review of assertions, not
GitHub-certified execution of native commands. Rerun, deletion, mixed approval,
changing source/scope or unavailable observations refuse new effects.

Anonymous template reads are confined to shk95/configs-host-template identity
and main ref. Complete original template Git verifies delivered revision/tree
and ancestry; authorized raw pair review binds compatibility. A tested provider
override can differ from the template's pre-release provider pin. Private token
access is never expanded to the template.

Transport validates and reobserves custody before original evidence projection
and publication. Only existing evidence TSV/template-pair rows and eleven-field
semantic evidence rows are produced. The review run/job identify custody, not the
native execution job. Original schemas, packages and historical authority remain
unchanged. New custody events or reducer revocation states require protocol design.

Journal cannot write review paths. Actual operator packet/index maintenance must
serialize publication, preserve completed initializer identity and immutable
packet/history custody. Source provides no packet issuer, approval POST or automatic
publisher. Bootstrap adoption, Release-* judgement, exceptional promotion approval,
manual/scheduled operating proof and host changes remain distinct gates.
