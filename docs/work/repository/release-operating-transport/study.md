at their approved source/control revisions, reachability and independent bootstrap
record. Retain full public/operating history; bind actual refs, blobs and config.

Provision a dedicated single-job writer run, independent credential-free wait and
inspection runs, and serialized operator reruns. Verify actual source/ref/event/job
and Environment secret isolation. A PAT allowlist does not prove that isolation.

promotion and exact wiring/provisioning require separate approval. Never enable a
preview flag or import a candidate's executable as trusted control.

Review endpoint-specific Contents, Pull requests, Checks, Commit statuses, Actions
read/write and Administration-read permissions on the selected repositories.

needed. Verify actual denied/allowed behavior; claims about permissions are not
receipts. Confirm Required checks/app15368, administrator/conversation enforcement,
no force/deletion, dev strict=true and master strict=false. Resolve stronger review
rules through reviewed source rather than bypassing them.

Bind actual representative domain evidence and exact workflow/tool blobs to the
candidate, master, merge tree and retained rules. Supply complete delivered
provider/template pairing where required. Choose source-bound semantic bootstrap

coverage blocks release. Synthetic fixture receipts cannot fill any of these cells.

## Expected effects of a separately approved manual cycle

1. Independently authenticate the master entry and exact request. Load complete
   immutable operating history/current index and exact retained context. Disabled
   or unresolved setup refuses; a new trigger never owns an old job by itself.
2. Publish original semantic intent and derived index through one-parent,
   expected-head/non-force records; confirm actual record head before an effect.
   A competing writer, changed context or unknown acknowledgement fences progress.
3. Reconcile exact batch-owned refresh branch/complete PR lookup. Publish only a
   qualified lock-only candidate; no-op/failure publishes nothing. Unknown or
   closed/foreign/ambiguous PR state refuses new POST. Verify current required checks
   before any separately allowed compatible-patch admission.
4. Revalidate exact candidate/base/protection/approval before promotion. Compare
   actual merged commit parents/tree/source; an unexpected result stops tags and
   never triggers automatic undo. Publish immutable fixed tag object/ref payloads;
   join exact successes and retain partial publication without changing versions.
5. Exercise fresh stop, explicit resume, lost acknowledgement and record conflicts.
   Resume requires reconciled effects and fresh validation/approval. Cancel only
   the single recorded owner job's isolated run; recheck run/attempt/jobs and prove
   termination before takeover. A timeout/202 alone proves nothing.
6. Observe actual Actions failure notification receipt and user-configured delivery
   separately. Wake acknowledgement is neither approval nor writer ownership.
   Preserve safe bounded public summaries without private paths, data or tokens.
