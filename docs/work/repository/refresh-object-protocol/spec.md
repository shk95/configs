Raw generated headers are exactly tree, one parent, author, committer in that order,
followed by one blank line. Message is exactly the following subject, blank line and
seven trailers in this order, each LF terminated; there is no other body/header:

```text
chore(unixlike-deps): refresh reviewed inputs

Release-Format: 1
Release-Domain: unixlike
Release-Impact: <none|patch|minor|major>
Release-Contracts: <sorted unique comma-separated identifiers>
Release-Compatibility: <compatible|breaking>
Release-Rationale: <nonempty single-line UTF-8 text>
Release-Migration: <none|docs-relative-path>
```

Identifiers match [a-z0-9][a-z0-9-]*. Rationale refuses NUL/CR/tab/control characters
and leading/trailing spaces. Migration is none or a nonempty docs/ relative path,
without dot/dot-dot segments, controls or leading/trailing spaces. Breaking requires
major and a migration path. Original pinned release-preview.awk owns domain mapping,
contract coverage, migration existence and remaining semantic declaration validation;
serialization never chooses impact or compatibility or certifies domain review.
Do not convert none/source-only/unknown to patch/compatible. Absent or unsupported
reviewed declaration returns a finite blocker in later transport, not invented bytes.
Fixtures include exact positive bytes and changed identity, epoch, subject, order,
duplicate/missing trailers, invalid UTF-8/framing and unsupported declaration refusal.
