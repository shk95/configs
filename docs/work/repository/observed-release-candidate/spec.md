## Candidate contract

Add an optional keyword-only immutable qualification envelope at Snapshot
construction and a no-argument propose_candidate operation. Old construction and
historical package readers remain supported. The envelope binds exact retained
control/manifest, literal baseline TSV and its digest and the reviewed requirement
set. Its canonical binding authenticates no review: actual private custody/adoption
is a separate operator gate. Reconstruct original bytes at each use and refuse
changed input or missing custody material. No caller verified evidence rows enter.

Independently bind current public refs and complete original Git objects; derive
the prospective promotion tree in an owned credential-free repository. Bind the
original baseline annotated tag and target commit, or independently reviewed
source-bound record/commit/tree/blob, to actual public API observations and original
local hashes. Execute only the verified retained production qualifier/classifier
in an owned no-checkout public-object copy with no credentials, hooks, filters,
ambient repository config, replacement refs, implicit fetch or candidate scripts.

Use a format-header-only evidence file for selection discovery. Only a complete
production diagnostic whose sole reason is missing-required-evidence can proceed.
Unknown coverage, invalid baseline, template pair, compatibility, defect or any
other refusal remains fatal. A no-op returns no proposal. Selected requirement IDs
must match reviewed trust exactly, including exact per-check expected tools.
Unsupported required review/template provenance is refused rather than invented;
this source does not observe another repository or human review receipts.

Acquire actual successful check/run/latest-attempt/job/workflow/tool blobs through
the existing Entry collector. Generate exact original preview TSV and rerun the
same production qualifier. Require a candidate with identical source/tree/rules,
baselines, selection, domain version/migration/approval decision. Source-only
results without a release impact cannot be encoded as patch/minor/major and refuse.
Retained rules/tool/baselines fields use SHA256 of respectively exact verified rules
bytes, canonical complete executing semantic manifest bytes and literal baseline
TSV bytes. Preview Git-blob digests are checked independently, never substituted.

Derive candidate generation, fields and source authentication framing, feed the
existing serializer/reducer and full prospective global replay, preserving old
history and approval invalidation. Do not invent release/tag object rows. Actual
evidence event publication remains the existing observed evidence operation.
Reobserve complete candidate/receipt/qualification/source/owner/job/head/stop
bindings around proposal and immediately before journal publication. Changed or
failed observations fence this instance before writes.
