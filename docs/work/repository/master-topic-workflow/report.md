## Evidence boundaries

Repository fixture execution is local Darwin evidence using disposable Git
repositories and simulated GitHub transport/settings. It is not actual remote
protection adoption, hosted CI, native Git for Windows execution, domain
configuration evaluation/build, activation or Windows Apply. None of those
lanes is claimed passed. Seven workflow fixtures include refusal to treat a
foreign PowerShell invocation as native Windows verification.

Actionlint from the existing pinned Unix-like nixpkgs input passes for the
changed CI workflow; Ruby also parsed the YAML. No flake input was updated.
Existing host outputs and domain release declarations are unchanged.

The whole version-control suite also exercises the existing retired-capture,
checkpoint, registry, history, selection and bounded publication fixtures.
Local temporary logs are supporting session output, not a private prerequisite
for running the tracked commands again.
