## Private attempt contract

A canonical format-1 private attempt envelope holds the complete unauthenticated
format-2 desired proposal and its exact digest, accepted source/transport/roles
bindings, independently reviewed seed/disabled-record/child-tree construction,
fixed author/date/message and the numeric initializer workflow/run/attempt=1.
Original source time supplies the reviewed child date. Actual seed parent is
independently acquired before reconstructing the exact child commit. The seed
creation API does not supply a reviewed parent identity in advance.

The only publishing authorization input is the fixed job Environment secret
CONFIGS_RELEASE_INITIAL_ATTEMPT, retained with the operator's private mode-0600
review file. No public request body, dispatch field, artifact, candidate, owner
transcript or caller boolean can authenticate it. The entry verifies actual current
master, full original transport and role/workflow definitions, numeric API runtime,
latest attempt=1 and the sole initializer job independently. Certificate equality
is required in addition to these observations. Its run/attempt/source/workflow may
not be substituted by current values. The dedicated token has no certificate or
Environment-secret rotation authority. The source cannot mint a later publishing
certificate. A new certificate requires maintainer review of preserved prior-attempt
disposition; this work supplies no automatic issuer or retry permission.

Desired format-2 bytes remain assertions and cannot enter legacy format-1 effects.
The new actual role-aware initializer must independently observe source/private
identities, full refs/default branch, exact role/package/record bindings and compare
the regenerated pure desired bytes to the reviewed envelope. Keep initializer stop
operator and disabled writer workflow/actors distinct. Do not simulate Entry or
reuse writer authority to represent an initializer.

## Finite behavior and publication

Publish only on the separately reviewed initialize action, one invocation in the
accepted original workflow, with a certificate for that exact run/attempt. Require
complete authenticated absence of all refs before the first seed attempt. A seed
from another invocation is not publishing resumption authority. An existing exact
initialized head is observed, never republished. An incomplete seed/history from a
prior invocation is pending/refused and requires separate reviewed recovery; this
increment supplies no seed/object/ref retry across invocations.

Within the one invocation retain existing fixed seed grammar, source-bound Contents
creation, complete original root/tree/sole-blob verification, prospective original
record replay, deterministic child construction and expected-head non-force ref
publication. Reauthenticate actual role/source/job/head before each write. Attempt
each write once. Lost seed/ref acknowledgements use independent observation only;
unknown object acknowledgement fences the invocation. No new endpoint class, token
grant, private write path or bootstrap enablement is introduced.

The separate observe action is read-only: acquire original objects/full refs and
reconstruct the reviewed expected initial child from its actual seed parent. It may
report an exact initialized identity or bounded absent/pending/refused status; it
never resumes publication, rotates authorization or converts absence into a new
attempt. A later invocation cannot publish with an old run certificate even when
old run metadata has been deleted. Preserve raw records/attempt identities privately;
public output is a fixed bounded enum with no private names, hashes or responses.

## Source entry and delivery

Add a dedicated original initializer module and an explicit operator subcommand;
retain the read-only preflight contract. Extend the exact trusted transport inventory
for that module while retaining original seven/six/five-file readers. The retained
eight-file semantic packages and legacy format-1 effects stay unchanged. Update role
declaration only with the actual initializer source job/Environment. The initializer
workflow is manual-only, one job, job-level concurrency cancel-in-progress=false,
finite timeout, accepted master/actor guards and credential-free owned Git/package
children. Inspector/wait and candidate code receive no token/private packet.

Missing private certificate, role/runtime mismatch or unavailable observations
refuse effects. Source workflow/metadata matches do not prove Environment branch
restriction, private independent review, certificate retention, permissions or
isolation. Keep the writer disabled. Do not dispatch the new workflow, promote
master, create records or configure secrets as part of this source lane.

Adopt the durable source contract in a decision/invariant/procedure with its source
implementation and positive/negative fixtures. Prepare a concrete operator custody
and review checklist for the later maintainer gate. Source acceptance is separate
from that gate and every parent operating bar stays pending.
