## Outcome and authority

only. Derive requests from the original package's exact approved payload and raw
object identity, never caller endpoint/body or hidden refresh-branch writes. Public

Blob body has only canonical base64 content and encoding=base64. Tree body has
complete direct path/mode/type/sha entries; no base_tree, recursive path, inline
content, deletion or partial merge. Commit body has exact tree, ordered parents,
message, author and committer; no defaults or signature. Durable original intent
precedes effects. Reobserve original source/owner/generation/job/head/stop and exact
prerequisite observations before each POST and journal publication.

POST 201 and matching acknowledgement SHA are insufficient. Independently GET the
exact typed SHA, verify complete data and reconstruct raw Git identity. For tree

changes expected bytes fences before refs. Preserve signed original base raw bytes;
GET JSON is not an original raw commit carrier. Compare its exact public SHA and
structural fields to independently hashed original bytes without inventing headers.

Observe every generated dependency through its original observed operation and
every original dependency through exact public identity. All generated objects must
be observed before any branch/ref/PR effect. Reuse only identical immutable object
identity, not a matching abbreviated SHA or supplied operation label.

unknown, never implicit retry permission. A 404 may hide authentication/visibility
failure. Qualify typed absence with fixed public repository ID/visibility and
successful same-channel known original objects of the same type before and after
the target read. Unavailable/moving qualification remains unknown. A POST
acknowledgement followed by missing independent observation fences the instance.
Use a fixed anonymous public-read channel, with public repository identity
1330390069 independently observed on 2026-10-04. Never forward writer credentials
or fall back to another channel on error. A later ownership/visibility change
returns to planning rather than changing the target authority automatically.

qualified applied/absent results plus explicit authorized takeover can permit an
identical payload/ID retry. New source instances cannot clear fences or invent
