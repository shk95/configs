## Implementation design and owned files

- A fixed launcher and loader admit only the literal public repository, constant
  package root, exact full object identities and supported protocols. Verify the
  supplied approved-master provenance, reachability, manifest and dependency
  digests before extracting and executing the retained package. Synthetic approved
  assertions are fixture inputs, not production provenance authentication.
- The retained package owns the record parser, reducer, classification/approval
  meaning, endpoint schemas and serializers. Manifest closure includes every
  executing R-preview/classifier dependency. Never mix old engine with mutable
  current rules, adapter, preview or classifier. Use isolated scratch and explicit
  tools; no candidate artifacts, cache or candidate code is executed.
- Strict TSV1 config/stop/history/index handling follows the parent's bounded
  original-byte grammar and fixed event tuples. Reconstruct the index from
  append-only events; refuse unexplained disagreement, unsafe paths or impossible
  transitions. Pinned config controls a batch; live stop is reread separately.
- Pure endpoint adapters consume supplied transcripts and produce exact proposed
  request/observation objects. They have no HTTP transport or credential path.
  Disposable file-only Git fixtures exercise operating parent conflicts and
  response gaps within the delivered fixture isolation boundary.
- The workflow exposes only an inert preview interface, no schedule trigger,
  secrets, Environment or enabled remote operation. Its ref/event guard, constant
  writer job concurrency with cancel-in-progress=false, independent inspector
  shape and bounded job/API/cancel/retry contracts are checked as source and
  simulated behavior. They are not a live writer, cancellation or secret test.
- Owned integration files are tool/configs route/help, controller launcher and
  package/manifest/protocol, narrow fixture wrapper and cases, repository suite
  and native CI wiring, necessary dispatch/runtime-doctor changes, README and
  CONTRIBUTING usage, owning decisions/invariants/registry, this child report
  and a bounded parent report link. No domain, scheduler or retirement code is
  owned by this lane. Preserve calendar tag policy and release-preview interfaces.
