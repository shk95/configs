## Source contract

The collector is a no-argument Snapshot operation. Its requirements are the explicit
independently reviewed trust set already bound at Snapshot construction; selected
ids must match exactly once. Requirements remain assertions until independently
observed. Bind all check/run/latest-attempt/job/numeric workflow identities, actual
public/head repository and acceptable source event, complete successful check result,
job URL/name and exact regular source workflow/tool blobs. Reject ambiguous,
missing, failed, stale, foreign or moving observations. Repeat the complete receipt
observation around projection and immediately before journal publication.

Observe current dev and master, independently bind their original local Git objects
to actual API identities/tree/parents, and reconstruct the proposed promotion tree
in an owned bare repository with a bounded local object pack. No checkout, hook,
external merge driver, ambient config, credential or remote transport reaches that
child. Refuse unavailable/incomplete objects, conflicts or a different tree. This
is prospective expected-tree proof, never an actual promotion receipt.

Derive the original retained evidence rows from observed identities and the pinned
candidate's exact dev/master/tree/rules/tool tuple. Append only missing exact rows to
the existing transcript, preserving all prior observations and obligations. Feed
these bytes through the existing original serializer/reducer and complete global
prospective replay. Existing stop/source/head/owner/job guards and per-instance
proposal/journal fences remain mandatory. A failure before or after projection
fences this collector; no partial/moving observation reaches a Git API write.

Use the existing finite GET endpoint classes, selected original retained package,
public-object plumbing and private journal path only. No broader permission,
credential source, network host or semantic schema. Update the exact transport
manifest without rewriting retained semantic packages or historical readers.
Actual reviewed trust provision, deployed source/job isolation, bootstrap and live
endpoint/protection/notification proof remain independent operating gates.

## Verification and stop conditions

Disposable real Git and synthetic API cover successful acquisition/publication,
non-ancestor clean merge, wrong/conflicting tree, absent/corrupt public objects,
credential-free child configuration, duplicate/missing requirements, failed/stale/
foreign checks, wrong workflow/tool mode/blob/job URL/name, latest attempt or job
movement, immutable transcript history, prospective replay and fresh publication
rechecks with no effects on refusal. Run narrow transport fixtures, normal hooks,
repository policy checks and exact-head native Git-for-Windows CI. No real API
mutation or token enters fixtures. Report source/local/native/operating separately.

Replan for new endpoints, source execution, wider token scope, changed retained
schema, unknown original objects or trust/ownership ambiguity. Preserve recovery
workspaces; no master promotion, tag, activation, Apply or cleanup.
