# execute work

Read project policy, procedure and the assigned plan when present. Confirm
the requested task authorizes its Git mutations. Pin local dev and reviewed
plan revision; create a dedicated topic worktree before editing. Do not fetch
origin/dev or require an issue/PR for pickup. Check existing ownership first.

Implement one coherent owning-scope outcome. Run narrow relevant checks,
record failed/unavailable evidence honestly and preserve acceptance. Before
integration, reflect current local dev in the candidate worktree, resolve
conflicts there and verify the combined result. Deliver the exact final SHA,
base, diff and evidence to integrate-work; sequential integration may occur
in the same authorized session. Local completion does not require push or CI.

Checkpoint useful unfinished state before interruption/replanning. Push,
master promotion, remote PR delivery and cleanup are separate explicit
operations. Retain existing remote recovery capabilities only when that
operation is requested; they do not govern normal local development.
